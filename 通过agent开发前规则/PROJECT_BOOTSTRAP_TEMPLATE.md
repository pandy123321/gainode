# 25. Project Start Contract

```text
DOCUMENT_BASELINE = FROZEN
MACHINE_CONTRACTS = FROZEN
INDEPENDENT_REVIEW = PASSED
OWNER_SIGNOFF = COMPLETE
REQUIRED_PRE_DEVELOPMENT_RUNTIME_GATES = PASSED_OR_FORMALLY_STAGED
OPEN_P0 = 0
OPEN_P1 = 0
OPEN_P2 = DISPOSITIONED
DEPENDENCIES = APPROVED
SECRETS_POLICY = FROZEN
DEPLOYMENT_POLICY = FROZEN
STAGE_PLAN = FROZEN
EXTERNAL_REVIEW_PROTOCOL = READY
```

后，才可以由有权责任人设置：

```text
FROZEN_FOR_DEVELOPMENT = YES
```

`DEVELOPMENT_START = YES` 应按项目计划另行授权。
